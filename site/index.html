About this list

A small index of a growing ecosystem.

MyGo apps are ordinary Go programs. They compile to a single binary of a few megabytes, open instantly, and can mix native widgets with a web view in the same window. That combination turns out to be good for the kind of tool you keep open all day: terminals, agent dashboards, music players, menu-bar utilities.

Every project here links to a public repository. Star counts and licenses were refreshed from the GitHub API on 2 November 2026. Five repositories from the original research had been deleted or made private by then and are not listed.
