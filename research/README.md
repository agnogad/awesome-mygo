# Research notes

`source-list-tr.md` is the seed for this list: a Turkish-language compilation of
repositories that use MyGo, merged from an earlier research pass, the
`awesome-mygo` and `awesome-mygo-apps` indexes, and a GitHub search.

It is kept here for provenance only. It is not maintained, it is not the source
of truth, and it is not linked from the README. The canonical data lives in
`data/curated.json`, which `scripts/parse.py` produced from this file on
2 November 2026.

Entries in the seed file were not re-verified during the import. The build
pipeline instead reads each repository's current metadata from the GitHub API,
and five repositories that no longer existed at that point were dropped.
